### Yoradio для ESP32-4848S040 (ST7701S RGB 480x480, 4.0")

1) Как включить плату в проект

- Скопируйте `src/myoptions_4848S040.h` поверх `src/myoptions.h`.
- **ВАЖНО:** В PlatformIO выберите environment `[env:4848S040]` из `platformio.ini` (или универсальный `[env:yoradio-esp32s3]`).
- Затем выполните очистку сборки в `.pioarduino`/PlatformIO (clean), чтобы конфигурация гарантированно применилась.

4) Особенности и пины

- Дисплей: ST7701S, 480x480, RGB Panel (16 линий данных)
- Тачскрин: GT911 (I2C: SDA=19, SCL=45)
- Подсветка: GPIO38 (PWM)
- Аудио (I2S): DOUT=40, BCLK=1, LRC=2
- SD-карта (SPI): CS=42, SCK=48, MISO=41, MOSI=47, частота 20 МГц
- GPIO48 и GPIO47 общие для SD-карты и командной шины дисплея ST7701. На GPIO48 также сидит встроенный RGB-светодиод модуля, поэтому в `myoptions.h` он отключён (`USE_BUILTIN_LED false`) — иначе SD не читается. При попытке включить его сборка остановится с ошибкой.
- Свободные пины: см. схему/даташит (по ревизии платы).

Технические характеристики

| Компонент | Характеристики |
|-----------|----------------|
| **Процессор** | ESP32-S3-WROOM-1-N16R8 (240MHz, dual-core) |
| **Память** | 520KB RAM + 16MB PSRAM + 8MB Flash |
| **Дисплей** | ST7701 RGB Panel 480x480 (16 линий данных) |
| **Тачскрин** | GT911 (I2C: SDA=19, SCL=45) |
| **Аудио** | I2S (BCLK=1, LRCLK=2, DOUT=40) |
| **Подсветка** | PWM (пин 38) |
| **SD карта** | FSPI (CS=42, SCK=48, MISO=41, MOSI=47) |

Жесты и управление (тачскрин)

- Поддержка тачскрина реализована.
- Влево/вправо — изменение громкости
- Вверх/вниз — выбор станции
- Нажатие — старт/стоп
- Короткое касание двумя пальцами (около полсекунды) — переключение SD<->Radio. Если плеер играл, воспроизведение продолжится в новом режиме; если стоял — останется остановленным.
- Режим также переключается из веб-интерфейса.

Статус SD

- SD-карта поддерживается начиная с версии 0.9.434m-r2.03: MP3 и FLAC, карта FAT32.
- Настройки в `myoptions.h`: `SDC_CS 42`, `SD_SPIPINS 48, 41, 47`, `SDSPISPEED 20000000`, `USE_BUILTIN_LED false`.
- Если карту вынуть во время воспроизведения, радио вернётся в режим Radio.
- Известные особенности:
  - инверсия дисплея (`invert`) при смонтированной SD-карте не применяется;
  - при воспроизведении возможны редкие подёргивания изображения;
  - при переключении Radio -> SD во время игры на экране на мгновение появляется строка `audio is not a file` — на работу не влияет.
